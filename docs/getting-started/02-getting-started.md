# Getting Started with ChainFunded

ChainFunded requires only a Web3 wallet to use — no account registration, no email, no KYC. This guide walks you through the three things you need before you can start a challenge.

---

## Step 1: Install a wallet

You need a browser wallet or mobile wallet that supports Ethereum. MetaMask is the most commonly used option.

- **Browser wallets:** MetaMask, Coinbase Wallet, Rabby, Rainbow
- **Mobile wallets:** MetaMask Mobile, Coinbase Wallet, Rainbow

Note: WalletConnect is supported — any WalletConnect-compatible wallet will work.

See [Supported Wallets →](./04-supported-wallets.md) for the full list.

---

## Step 2: Switch to the correct network

ChainFunded currently runs on **Ethereum Sepolia** (testnet). You must switch your wallet to Sepolia before connecting.

In MetaMask: select the network dropdown at the top → select **Sepolia Test Network**. If Sepolia is not listed, select **Add Network** and add it manually.

Note: Sepolia is a test network. ETH and USDC on Sepolia have no real monetary value outside the ChainFunded platform.

---

## Step 3: Get USDC on Sepolia

You need USDC on Sepolia to pay the evaluation fee. There are two ways to get it:

1. **Fiat on-ramp** — use the built-in "Pay with Card" option on the Start Challenge page to purchase USDC via Stripe and pay the fee in one step
2. **Sepolia faucet** — obtain test ETH from a Sepolia faucet and bridge/swap to USDC

You also need a small amount of Sepolia ETH (~0.01 ETH) to pay gas fees on transactions.

---

## Step 4: Connect your wallet to ChainFunded

Go to the ChainFunded app and select **Connect Wallet** in the top-right corner of the navigation bar. Approve the connection request in your wallet.

See [How to Connect Your Wallet →](./03-connect-wallet.md) for a full walkthrough.

---

## Step 5: Start a challenge

Select **Start Challenge** in the navigation bar, choose an account size, and pay the evaluation fee.

See [How to Start a Challenge →](../challenges/03-start-a-challenge.md) for a full walkthrough.

---

## Summary

| Step | What you need |
|------|--------------|
| Wallet | MetaMask or any WalletConnect wallet |
| Network | Ethereum Sepolia |
| Funds | USDC (evaluation fee) + a small amount of ETH (gas) |
