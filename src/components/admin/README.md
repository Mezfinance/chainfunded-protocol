# admin/ — Admin Dashboard Components

Components for the platform admin panel (accessible only to wallets listed in `VITE_ADMIN_ADDRESSES`).

## Files

| File | Purpose |
|------|---------|
| `ChallengeManager.jsx` | View and manage all active challenges — status, trader details, manual actions |
| `PayoutQueue.jsx` | Review pending payout proofs, approve/reject, monitor payout execution |
| `TradablePairsManager.jsx` | Add, remove, or configure tradeable asset pairs and their data sources |
